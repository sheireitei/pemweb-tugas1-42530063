# Rachel's Dev Portfolio

Website portofolio pribadi yang dirancang untuk menampilkan profil teknis, proyek unggulan, tech stack, dan sertifikasi.

Live Preview: https://sheireitei.github.io/pemweb-tugas1-42530063/

---

##  Fitur Utama

- *Desain Responsif:* Tampilan optimal di perangkat mobile, tablet, dan desktop.
- *Aksesibilitas (a11y):* Menggunakan elemen HTML semantik dan navigasi keyboard yang ramah pengguna.
- *Galeri Proyek Interactive:* Menampilkan studi kasus proyek lengkap dengan deskripsi dan tech stack.
- *Form Kontak:* Memudahkan klien atau rekruter untuk menghubungi langsung via email.
